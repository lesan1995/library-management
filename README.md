# Library management system

Hệ thống quản lý thư viện sử dụng **Spring boot 3 + JPA + MySQL**

## Tính năng chính
- CRUD sách (Thêm, xem)
- Mượn sách và trả sách (Kiểm tra business rule)
- Xử lý exception toàn cục(Global exception handler)
- API document với **Swagger UI**
- Sử dụng DTO + Mapper(Không lộ entity)
- Transaction management
- Validation và exception handling

## Công nghệ sử dụng
- **Backend**: Spring boot 3, Spring data JPA, Spring web
- **Database**: MySQL
- **Mapping**: Lombok, Manual mapping
- **Documentation**: Swagger
- **Build tool**: Gradle
- **Java**: JDK 21
